- Python ≥ 3.10
- 依赖：`numpy pandas scipy openpyxl coptpy`（matplotlib 可选）
- COPT 求解器：问题一/三的 0-1 整数规划默认调用 `coptpy`；
  若未安装则自动回退到 `scipy.optimize.milp`（HiGHS），结果一致、速度略慢。

```bash
python problem4.py        # 约 10 秒（自动继承/重跑问题三）

```

## 3. 公共物理模型（common.py，四问统一口径）

**坐标系**：以 O01 为原点的局部切平面坐标（等距圆柱近似，单位 m），
DEM 双线性插值取高程。

**航段模型**（附录 2）：任意两节点取水平直线航段，
巡航海拔 = 航线经过 DEM 像元最高地面高程 + 50 m；
O01 作业高度 = 地面海拔，服务区作业高度 = 地面海拔 + 30 m。

- 飞行时间：`t = h_up/v_up + d/v_cruise + h_down/v_down`
- 等效航程：`L_g(q) = L_g0 - (L_g0 - L_gF)·(q/Q_g)^(3/2)`
- 航段能耗：`E = E_hor + E_up`
  - 水平巡航能耗 `E_hor = E_use · d / L_g(q)`（按等效航程占比折算电池可用能量）
  - 爬升附加能耗 `E_up = (m0 + q)·g·h_up / η_up / 3.6e6`（kWh，η_up = 0.72）
  - 下降能耗效率为 0，不单独计下降能耗
- 返航安全余量：`ΣE_航段 ≤ (1 - ρ_g)·E_use`，ρ_g = 20%
- 多点架次逐航段按**剩余载荷动态更新** q 计算能耗（每投送一站即扣减）

**地面作业时间**：架次开始 = 固定准备 300 s + 每箱装载 30 s；
每个服务区交接 = 基础 150 s + 每箱增加 30 s；
架次结束时刻 = 返回 O01 时刻（含全部准备/装载/飞行/交接时间）。

**充电模型**（两阶段等效充电，附录 2 公式）：
SOC < 90% 时 `t_chg = T_full·[0.65·(0.90-s)/0.90 + 0.35]`，
否则 `t_chg = T_full·0.35·(1-s)/0.10`。再次投入任务前须充至 100%。

**通信模型**（附录 3）：

- 有效接收门限 `P_th = P_sens + M = -90 dBm`
- 双向链路门限取两方向最大允许损耗的较小值：
  运输无人机↔G01 = **122 dB**，运输无人机↔中继（接入）= **116 dB**，
  中继↔G01（回传）= **126 dB**
- 总损耗 = FSPL(2400 MHz) + 地形遮挡附加损耗（LOS 被 DEM 遮挡时 +10 dB）
- 代码含快速带通判定：FSPL 超门限直接判不可用；FSPL+10 dB 仍达标直接判可用；
  仅不确定带做 LOS 射线检测（30 m 步长）

## 4. 各问题模型与算法

### 问题一（problem1.py）

1. **最大安全载荷矩阵（3 机型 × 15 服务区）**：能耗随载荷单调增，
   对每个 (机型, 服务区) 在 [0, Q_g] 上二分搜索满足返航余量的最大载荷。
   结果：A/B 型在全部服务区均达额定载重（25/30 kg），C 型 58.5~80 kg
   （S008、S002、S003、S012 受地形/距离限制）。
2. **货箱组批**：枚举每个服务区的全部可行批次（重量/体积/能量三重约束），
   建立**集合划分 0-1 整数规划**（每箱恰好覆盖一次），
   字典序三层优化：最少架次 → 最小能耗 → 最小累计作业时间。
   结果：**18 架次、总能耗 59.20 kWh、累计作业时间 32699 s**。
3. **敏感性分析**：ρ ∈ {10%,15%,20%,25%,30%}，总架次 18→18→18→19→20，
   平均最大安全载荷持续下降，呈现明显临界效应（ρ 提高使部分服务区
   原本可同批的货箱被迫拆分为新架次）。

### 问题二（problem2.py）

- **两层结构**：路线层（ALNS）+ 资源层（事件驱动排程）。
- **ALNS 大邻域搜索**：随机/最差移除 + regret 插入修复 + 架次内 2-opt + 机型再优化；
  模拟退火接受准则；3 个随机种子取最优。
- **资源排程**：按架次内最紧急硬时限排序，依次分配最早可用的同型实体无人机
  （A×4、B×2、C×2）与同型共享电池（6/4/4 组，含 SOC 与充电周转）。
- **目标（标量化字典序）**：医疗/首批硬超时 ≫ 加权 tardiness ≫
  全部任务完成时间 ≫ 能耗 ≫ 架次数。
- 结果（本机种子）：**17 架次，医疗/首批 0 超时，Cmax ≈ 12009 s，
  总运输能耗 ≈ 65.6 kWh**，输出逐箱交付时刻与资源甘特数据，
  并自动检验无人机时间轴、电池占用/充电不重叠、返航 SOC 下限。

### 问题三（problem3.py）

1. **通信缺口识别**：对每个运输架次重建三维轨迹
   （爬升/巡航/下降/投送悬停），dt = 5 s 逐时刻判定直连链路，
   提取直连不可用的**时空通信需求区间**（本方案共 16 个）。
2. **候选悬停点**：缺口包围盒内 400 m 网格 × 离地 {60,120,180,240,300} m，
   预计算回传链路（→G01）与接入链路（→运输无人机轨迹）双向可行性。
3. **时空集合覆盖**：允许**一架中继同时服务多架运输无人机**
   （题目仅限制每架运输无人机任一时刻至多一个通信提供方），
   同点可连续覆盖的区间合并为候选中继任务（含能量/建链时限验算），
   用 COPT 求最少中继架次的集合覆盖。
4. **上机排程与联合迭代**：中继任务不可延迟（延迟即失去覆盖意义），
   排不下时拆分重试；仍排不下则**反向调整运输方案**——
   对相应运输架次施加最小延迟（保护医疗/首批硬时限），级联推迟
   同机/同电池后续架次，重新迭代。
5. 结果：**4 个中继架次覆盖全部 16 个缺口区间，0 次运输延迟，
   中继总能耗 6.12 kWh，联合任务完成时间 12206 s，医疗/首批 0 超时**。
   权衡分析：中继数量从 4 架次起每减少都会导致覆盖缺口或运输延迟；
   若强制“一架中继一次只服务一架运输无人机”，则需 16 架次中继
   并产生约 3×10⁴ s 运输延迟（代码中可通过限制候选任务覆盖集大小复现），
   说明中继多链路复用是本场景的关键增效点。

### 问题四（problem4.py）

1. **不可拆任务块**：并查集合并同一运输架次涉及的服务区，15 区 → 7 块。
2. **约束图分区**：对 K=2、K=3 精确枚举任务块的全部分配
   （去组标号对称性），输出 Pareto 两端方案：
   - **资源最小**：K=2 总资源 21（工作量差 43739 s）；K=3 总资源 24（差 45047 s）
   - **均衡最优**：K=2 总资源 25（**工作量差 224 s**）；K=3 总资源 30（差 10348 s）
3. **资源核算**：按各组时间轴计算运输无人机/电池（含充电占用）/
   中继无人机/能源组件的**最大并发占用量**（区间图峰值），
   跨组中继架次在每个被服务组分别计入（不可跨组调配的保守口径）。
4. **缺口分析**：中继无人机（库存 2 架）是所有分区的瓶颈资源，
   均衡方案缺口更大（K=3 均衡需 5 架，缺 3 架）；
   缺口根本原因是分区后各组须独立覆盖本组并发峰值，产生重复配置。
   结论：分区越多、越均衡，独立执行所需的冗余资源越多；
   若库存受限，应采用偏集中的分区（资源最小方案）。

## 5. 主要建模假设（论文中需交代）

1. 水平巡航能耗按“等效航程占比 × 电池可用能量”折算（附录 2 只给出
   等效航程关系与能耗构成，未给显式公式，此为最自然的口径）；
2. 爬升附加能耗 = 总质量 × g × 爬升高度 / 爬升能耗效率；
3. 架次时间轴含固定准备与装载时间（t=0 为架次开始）；
4. 箱交付完成时刻 = 所在服务区交接作业完成时刻；
5. 一架中继无人机可同时为多架运输无人机提供中继
   （题目仅限制运输无人机侧的唯一提供方）；
6. 通信判定从起飞（准备/装载完成）开始，至返回降落结束；
7. 问题四资源需求按各组内时间轴的最大并发占用量核算。
