# 山区洪涝灾害下无人机运输与通信协同优化

> **2026 年中国研究生数学建模竞赛（"华为杯"）D 题 · 完整求解方案**
>
> 面向"断路、断电、断网"的山地洪涝灾害场景，研究无人机应急物资运输、通信中继与救援资源配置的协同优化：80 个不可拆货箱、15 个服务区、8 架异构运输无人机、共享电池池、2 架中继无人机、30 m DEM 地形与无线链路参数，四问递进（单点组批 → 多点多架次调度 → 运输-通信联合调度 → 任务分区与资源配置），全部基于官方附件数据，结果与提交模板逐列对应。

---

## 一、问题背景

2026 年 7 月，受台风"美莎克"持续强降雨影响，广西横州市镇龙乡发生严重洪涝灾害，核心受灾区域一度交通中断、通信不畅，约 8000 人受困，食品、饮用水、药品需依靠空中投送。本题目以镇龙乡及周边山区为地理背景，设置标准测试场景：1 个临时调度中心（O01）、15 个服务区（S001–S015）、80 个不可拆货箱（含医疗物资与首批保障货箱，带硬时限）、A/B/C 三种运输机型共 8 架实体无人机及配套共享电池组、中继无人机与可更换能源组件、30 m 分辨率 DEM 及无线链路参数。

**核心需求**：

- 山区地形起伏大、道路受损，无人机成为唯一可靠的运输手段；
- 运输全程（爬升/巡航/下降/投送）须保持连续通信，直连网关不可用时需空中中继保障；
- 灾后救援可能分区独立执行，需评估不同分区方式的资源配置、冗余与缺口。

## 二、四个问题与求解思路

### 问题一：单点往返运输能力与货箱组批

- **最大安全载荷矩阵**（3 机型 × 15 服务区）：能耗随载荷单调增，对每个（机型, 服务区）二分搜索满足返航安全余量 `ΣE ≤ (1-ρ)E_use` 的最大载荷。C 型在 S008/S002/S003/S012 受地形与距离限制（58.5~80 kg）。
- **货箱组批**：枚举全部可行批次（质量/体积/能量三重约束），建立**集合划分 0-1 整数规划**（每箱恰好覆盖一次），字典序三层优化：最少架次 → 最小能耗 → 最短累计作业时间。
- **敏感性分析**：ρ ∈ {10%…30%}，呈现明显临界效应（架次数 18→18→18→19→20）。

### 问题二：异构无人机多点多架次运输调度

- **两层结构**：路线层（ALNS 大邻域搜索：随机/最差移除 + 最便宜插入 + 2-opt + 机型再优化，模拟退火接受准则，3 随机种子取优）+ 资源层（事件驱动贪心排程：按硬时限排序分配最早可用的同型实体机与共享电池，含两阶段充电周转）。
- **目标**（标量化字典序）：医疗/首批硬超时 ≫ 加权配送 tardiness ≫ 全部任务完成时间 ≫ 运输能耗 ≫ 架次数。
- **结果**：17 架次、医疗/首批 0 超时、Cmax = 12009 s、总能耗 65.58 kWh，输出逐箱交付时刻与资源甘特，并自动检验无人机时间轴、电池占用/充电不重叠、返航 SOC 下限。

### 问题三：通信约束下运输与中继联合调度

- **缺口识别**：对每个运输架次重建三维轨迹（爬升/巡航/下降/投送悬停），dt=5 s 逐时刻判定直连链路，提取"直连不可用"的时空通信需求区间（共 16 个）。
- **候选悬停点**：缺口包围盒内 400 m 网格 × 离地高度 {60…300} m，预计算接入链路（U↔R）与回传链路（R↔G01）双向可行性（FSPL 带通 + LOS 射线检测）。
- **时空集合覆盖**：一架中继可同时服务多架运输无人机（题目仅限制运输侧唯一提供方），同点可连续覆盖的区间合并为候选中继任务（含能量/建链时限验算），COPT 求最少中继架次的集合覆盖（回退贪心）。
- **上机排程与联合迭代**：中继任务不可延迟，排不下时拆分重试；仍排不下则反向调整运输方案——对相应运输架次施加最小延迟（保护医疗/首批硬时限）并级联推迟同机/同电池后续架次。
- **结果**：4 个中继架次覆盖全部 16 个缺口区间，0 运输延迟，中继能耗 6.12 kWh，联合任务完成时间 12206 s。若强制"一架中继一次只服务一架运输无人机"则需 16 架次中继并产生约 3×10⁴ s 运输延迟——**中继多链路复用是本场景的关键增效点**。

### 问题四：救援任务分区与资源配置

- **不可拆任务块**：并查集合并同一运输架次涉及的服务区（题目规定），15 区 → 7 块。
- **约束图分区**：对 K=2、K=3 精确枚举任务块全部分配（去组标号对称），输出 Pareto 两端方案（资源最小 / 均衡最优）。
- **资源核算**：按各组时间轴计算各类资源的**最大并发占用量**（区间图峰值，含充电占用）；跨组中继架次在各被服务组分别计入（不可跨组调配的保守口径）。
- **结论**：中继无人机（库存 2 架）是所有分区的瓶颈资源；分区越多、越均衡，重复配置越严重。若库存受限，应采用偏集中的分区（资源最小方案：K=2 总资源 21）。

## 四、创新点

1. **多链路复用中继**：突破"一架中继一架运输"的朴素理解，允许中继并发服务多架运输无人机（严格依据题目规则），将中继需求从 16 架次压缩到 4 架次；
2. **运输-通信联合迭代**：通信缺口 → 中继规划 → 排程冲突 → 最小运输延迟 → 再规划，形成闭环，并以 1e6 级硬惩罚保护医疗/首批时限；
3. **字典序 MILP 组批与覆盖**：问题一集合划分、问题三集合覆盖均用 COPT 精确求解，层级目标逐层固定；
4. **资源感知的 ALNS**：路线搜索与实体机/电池排程耦合评估（每个候选解都做排程可行性检验）；
5. **区间图峰值核算**：问题四资源需求按各组时间轴最大并发占用量精确核算（而非平均/总量）；
6. **规划中的创新点**：Pareto 权衡前沿、下界认证、通信感知的候选解联合优化、悬停点连续精修、通信余量报告、K=1..4 分区扫描（实现方案见《补充核查与创新点实施方案.md》第五节）。

## 七、建模假设与口径（论文需披露）

1. 水平巡航能耗按"等效航程占比 × 电池可用能量"折算（题目未给显式公式，见附录 2 能耗构成式的自洽口径）；
2. 爬升附加能耗 = 总质量 × g × 爬升高度 / 爬升能耗效率（η=0.72）；
3. 架次时间轴含固定准备与装载时间（t=0 为架次开始）；箱交付完成时刻 = 所在服务区交接作业完成时刻；
4. 一架中继无人机可同时为多架运输无人机提供中继（题目仅限制运输侧唯一提供方）；
5. 通信判定从起飞（准备/装载完成）至返回降落；问题四资源需求按各组时间轴最大并发占用量核算。

- **资源可行性**：无人机时间轴无重叠；电池占用+充电时段无重叠；返航 SOC ≥ 下限（problem2 内置自动检验）。
- **通信全覆盖**：`_verify_q3_link.py` 逐区间复核中继覆盖（服务窗口包含 + 全采样点链路可用）。
